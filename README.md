# The New Spark

Web oficial de **The New Spark**, barbería con sistema de reservas, catálogo de servicios, productos, contacto y panel privado de administración.

El proyecto está construido con **Next.js**, **React**, **TypeScript**, **Tailwind CSS** y **Supabase**.

---

## Estado del proyecto

Actualmente el proyecto incluye:

- Página principal pública.
- Sección de servicios.
- Sección de productos.
- Formulario de reserva.
- Contacto público.
- Integración con Supabase.
- Panel privado en `/panel`.
- Gestión de citas en `/panel/citas`.
- Login privado con usuario y contraseña.
- Protección básica contra intentos fallidos.
- Base preparada para la futura fase de clientes y fidelidad digital.

---
